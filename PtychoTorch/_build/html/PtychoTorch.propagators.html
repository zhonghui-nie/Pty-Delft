PtychoTorch.propagators.asp.cached_scaledASP_quadratic_phases(N: int, dx: float, dq: float, wavelength: Tensor, z: Tensor, compute_Q3: bool = False, bandlimit: bool = True)¶

Calculate quadratic phases Q1, Q2.

Q1 and Q2 are calculated in a single step, improving numeric accuracies. However, the whole calculation is repeated when chaning wavelength/z. Refer to cached_scaledASP_quadratic_phases_dynamic_z_wavelength for a faster implementation.

Parameters:

  • N – Number of pixels

  • dx – Pixel size in sample-plane (m)

  • dq – Pixel size in detector-plane (m)

  • wavelength – Wavelength (m)

  • z – Distance to camera (m)

  • compute_Q3 – If set to true, then the phase-correcting term Q3 will also be calculated. If only amplitudes are of interest, Q3 can be neglected. If set to False, then None is returned for Q3.

Returns:

Q1, Q2, Q3

PtychoTorch.propagators.asp.cached_scaledASP_quadratic_phases_dynamic_z_wavelength(N: int, dx: float, dq: float, wavelength: Tensor, z: Tensor, device: str | device | int, compute_Q3: bool = False, bandlimit: bool = True) → tuple[Tensor, Tensor, Tensor | None]¶

Calculate quadratic phases Q1, Q2.

Here, calculation steps involving wavelength and z are performed separately to the remainding of the exponent. This enables caching part of the calculations, at cost of numeric inaccuracies. If wavelength and z are constant, please refer to cached_scaledASP_quadratic_phases_dynamic method.
