PtychoTorch.utils.pad_or_crop(img: Tensor, new_shape: Size | tuple[int, ...] | int, padding_val: float = 0) → Tensor[source]¶

Pads or crops img to new_shape

If new_shape is smaller/larger than img.shape, then img will be cropped/padded to new_shape, keeping img centered. Only the last two dimensions of img are affected.

Parameters:

  • img – image, or batch of images, to be padded/cropped. Must be at least 2-dimensional.

  • new_shape – shape to pad/crop to. If only integer is provided, then a square shape is assumed with length new_shape.

  • padding_val – Value used for padding

Returns:

img with updated shape
